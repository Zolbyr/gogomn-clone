# Self-hosted typography

Variable WOFF2 files from the Google Fonts CSS API, with Latin, Latin Extended,
Cyrillic and Cyrillic Extended subsets (including Mongolian Өө and Үү).
Fonts load from this project without external runtime requests.

- **Manrope**, Mikhail Sharanda. Headings, weights 500–800.
  [Source](https://github.com/google/fonts/tree/main/ofl/manrope),
  license: `manrope-OFL.txt`.
- **Golos Text**, Alexandra Korolkova and Vitaly Kuzmin. Body/UI, weights 400–700.
  [Source](https://github.com/google/fonts/tree/main/ofl/golostext),
  license: `golos-text-OFL.txt`.

Subset declarations and Unicode ranges are in `app/fonts.css`.
