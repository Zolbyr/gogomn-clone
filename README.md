# Gogo clone (Next.js)

gogo.mn-ээс санаа авсан мэдээллийн порталын demo төсөл. Next.js (App Router), React, JavaScript.

## Ажиллуулах
```bash
npm install
npm run dev   # http://localhost:3000
```

## Бүтэц
- `app/`: хуудсууд (нүүр, ангилал, мэдээ, хайлт)
- `components/`: Header, Nav, ArticleCard, ArticleRow, Popular, Thumb, Footer
- `lib/data.js`: жишээ өгөгдөл (бодит мэдээ биш)

## Цаашид
Бодит API/MongoDB холбох, хуудаслалт нэмэх, тест бичих.
